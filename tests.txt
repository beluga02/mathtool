# Тесты mathtool. Запускать из каталога репозитория.
# Блоки разделены строкой "-----". Поля: Команда, stdin, stdout, stderr, Код возврата.
# Содержимое stdout/stderr приведено знак в знак (после поля — строки до следующего поля).
# Справка argparse снята при ширине терминала 80 символов (COLUMNS=80), Python 3.10+.
# Тесты с конвейером проверяются по выводу; код возврата — на запусках без конвейера.
# Два теста с вводом коэффициентов с клавиатуры (stdin: вручную) проверяются вручную;
# в них приведено то, что видит человек: введённые значения отображаются терминалом.
# Для ratio погрешность убывает примерно в 10 раз при росте числа шагов в 10 раз
# (шаги 100, 1000, 10000: 16.8569, 16.9459, 16.9545; точное значение 16.9555).
# На root с симметричным промежутком погрешность убывает быстрее — свойство задачи.
